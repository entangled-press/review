# Review of Creative Practice and Technology

**Interviews across Art, Design, and Games**

テクノロジーと表現が接続する現場を、当事者へのインタビューとして記録し続けるオープンなアーカイブ誌。発行: [Entangled Press](https://github.com/entangled-press)。

## この誌について

技術と表現のあいだには、教育・展示・制度の現場で日々実践が生まれているのに、記録されず、引用できる形で残らないまま消えていく知が多くあります。本誌はその知を、キュレーター、アーティスト、エンジニア、研究者、ゲーム開発者へのインタビューとして構成・編集し、恒久的に引用可能な形で蓄積します。

[Plurality](https://github.com/pluralitybook/plurality) の方式にならい、**GitHubリポジトリを原稿の正本**とし、Webサイトはそれを読むためのビューワーです。

## 構成

```
content/interviews/   記事の正本（Markdown + メタデータ）。三桁の通し番号で刻む
src/                  Webビューワー（Astro）
EDITORIAL.md          編集フロー・許諾・恒久性のポリシー
```

## 引用について

各記事の末尾に推奨引用形式を記載しています。基本形:

> 話し手名, 「記事タイトル」 *Review of Creative Practice and Technology* #001, Entangled Press, 2026. URL

記事のURLは恒久的に維持します。DOI付与（Zenodo連携）とISSN取得を準備中です。

## インタビューデータの取り扱い

録音・文字起こし等の生データはこのリポジトリに含まれません。掲載されるのは、話し手本人が構成原稿を確認し、公開を許諾した記事のみです。詳細は [EDITORIAL.md](EDITORIAL.md)。

## English

*Review of Creative Practice and Technology* is an open, ongoing archive of interviews documenting where technology and creative expression meet — across art, design, and games. Published by Entangled Press. Each issue is an edited, interviewee-approved conversation, maintained in this repository as the canonical source (in the spirit of [Plurality](https://github.com/pluralitybook/plurality)) and rendered on the web.
